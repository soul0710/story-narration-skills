# Story profiles: dramatic vs calm

Set `project.json.profile`. The profile changes defaults and which warnings appear; it never turns a
taste rule into a hard error. Rule classes follow drama-skills: **structural invariants** (ids, runtime
sum, plant-before-payoff, dead characters, knowledge order) are errors; **craft defaults** and **taste
options** are warnings the writer may override with a reason. Length, dialogue ratio and turn positions
are never proof of quality.

| | dramatic (default) | calm |
|---|---|---|
| For | family secrets, revenge, mystery, romance with obstacles, folk horror, historical | healing / slice of life, nostalgia, contemplative walks, piano-covered storytelling |
| Macro shape | beat map + four-phase intensity curve (structure.md §3, §5) | four movements: open 10–15% · wander 55–65% · settle 15–20% · warm close ~10% |
| Conflict | external + internal, escalating | small want + gentle obstacle; the turn can be inner (a decision to open up, let go, return) |
| Chapter ends | a hook (hooks-and-retention.md) | a soft pull: an image, a question, a promise of the next place; strong cliffhangers optional |
| Payoffs | pressure → release, ★-scaled | recognition, reconciliation, understanding, beauty noticed |
| sn.py extra warnings | dead zones >10 min, peak not in final 30%, midpoint position, missing `choice` in Acts 2–3 | none of those |
| Cold open | a hook in motion | an inviting image in motion + one concrete question or promise |
| Narrator | restrained, can foreshadow | warm, unhurried, sensory; fewer foreshadowing lines |

Both profiles still require: every chapter turns something (purpose + turn), a cold open, plants before
payoffs, continuity, generable visuals, runtime within tolerance.
