# sn-shots — Narration → shot script + narration map

`{studio}` = the sibling `sn-studio` skill directory. Read `{studio}/references/generability.md`,
`{studio}/references/narration-format.md`, `bible/characters.md` (visual signatures),
`bible/world.md` (era, location anchors).
Also read `{studio}/references/ai-film-production.md` §3–7 for reference handoff, first-frame planning
and production iteration. This skill still writes shot scripts, not image/video prompts.

Precondition: the chapter exists and passes `sn.py duration` and `sn.py continuity`.
The story layer owns the drama; the shot layer owns the camera (shuohao). Never change story content
here — if a chapter can't be shot as written, report the exact lines and send it back to `sn-write`.

## Step 1 — Downstream skill (ask once if unclear)

- **Calm prompt skills** (scene or storyboard) — contemplative, piano-covered storytelling: very slow
  constant camera, one moment per shot. Uses the field **`Nhạc`**.
- **Cinematic prompt skills** (scene or storyboard) — any genre and intensity, cinematic coverage. Uses **`Âm thanh`**
  and **`Hình ảnh`**. If the target skill isn't installed where the user will run it, say so.
Clip length default 8 s. At the project rate, one clip holds `8 × rate / 60` syllables (24 at 180/min).

## Step 2 — STYLE ANCHOR (once per project, copied into every chapter file)

Five core fields (required by calm prompt skills; `sn.py shots` checks them) + extended fields for cinematic ones:

```markdown
# [Tên video] — Chương NN: [Tên chương]

## STYLE ANCHOR
- Thể loại / ý đồ đạo diễn: [...]
- Mùa / thời điểm: [...]
- Bảng màu: [...]
- Chất phim: [...]
- Ống kính / mood: [...]
- Nhân vật / motif cố định: [each principal's verbatim visual signature from the bible]
- Ánh sáng: [...]
- Nhịp / âm thanh: [voice-over and music are added in post; generation = ambience only]
- Đầu ra: [prompt skill: scene | storyboard]; 16:9; clip 8 giây
```

Keep signatures and location anchors word-identical across all chapter files (continuity lock,
drama-skills). Pin the era concretely.
Confirm the output ratio (default 16:9); record fps only if supplied or required for a real render,
never as a made-up prompt guarantee. Reuse the bible's reference plan; if images are missing, name
the needed assets in the handoff without blocking shot writing or inventing attachment IDs.

## Step 3 — Cut the chapter

First let the script cut the narration:

```bash
python3 {studio}/scripts/sn.py segment <dir> --ch N [--clip 8]
```

It writes `shots/loi_dan_chNN.md`: sentence-boundary segments of about one clip each, a new segment at
every scene heading, pauses absorbed into clips. Don't cut at every `[HÌNH]` or `[NGỪNG]` — in the pilot
that produced 50 clips (6:40) for 4:45 of narration; scene-level cutting gave 40 clips (5:20). You may
merge/split segments by hand (keep numbering continuous). Then write one SHOT per segment:

**`shots/kich_ban_chNN.md`** — prompt script only, no narration text:

```markdown
## SHOT 01
- Cảnh: [space; start state → one common, visible action → end state; from the nearest [HÌNH], made concrete]
- Cảm xúc: [what the viewer feels/realises]
- Hình ảnh: [shot size, angle, lens, composition, focus, light source]     ← cinematic only
- Máy quay: [one camera move; calm: very slow, constant speed]
- Nhạc: [piano/music direction for post]                                   ← calm  (cinematic: "- Âm thanh:")
- Liên kết: [what carries over from the previous shot; what leads into the next]
```

**`shots/loi_dan_chNN.md`** — the editor's narration map (generated by `segment`), same shot numbers:

```markdown
## SHOT 01
Chiều hôm ấy mưa từ trưa chưa ngớt.

## SHOT 02
(im lặng)
```

Rules:
- Every spoken word of the chapter appears exactly once in `loi_dan`, in order (dialogue lines may keep a
  `[Tên]` prefix; `sn.py` ignores it). Silent shots: `(im lặng)`.
- One moment per shot; visuals generable (generability.md); risky shots keep `(rủi ro cao)` + fallback.
- `Cảnh` makes the drawable first state explicit, then the action and end state. `Cảm xúc` is the
  intended effect; put its visible carrier in `Cảnh`. Image creation locks that first state before
  I2V adds motion. Do not put a completed action in the initial still and replay it in video.
- Before handing off, check purpose, size/angle, motivated lighting, audio layer, references and
  status using ai-film-production.md §4. Use the existing fields; any requested production-status
  table stays outside the two fixed-format files. One camera choice applies per continuous shot;
  a downstream storyboard may use one choice per subshot with cuts, not one move for the whole clip.
- Visualise, don't caption: dialogue scenes show faces, hands in simple actions, objects, reactions — no
  on-screen text.
- Continuity across shots: time of day, weather, wardrobe, props in hand, eyelines, direction of travel;
  place changes get a visible transition. Characters dead before the story appear only in clearly marked
  memory shots.

## Step 4 — Verify ⛔

```bash
python3 {studio}/scripts/sn.py shots <dir> --ch N [--clip 8]
```

Errors: missing anchor fields, missing SHOT fields, narration inside the prompt script, numbering gaps,
`loi_dan` not covering the chapter's narration exactly and in order. Warnings: overloaded shots (too many
syllables for the clip), clip runtime far from narration runtime. Fix and re-run until PASS.

Then report shot count and clip runtime vs narration runtime, and tell the user the next step, e.g. give
`shots/kich_ban_ch01.md` to the storyboard prompt skill, and use `shots/loi_dan_ch01.md` + `export/narration.txt`
when laying the voice-over in the edit.
Mention planned/missing references and that first images need visual approval before animation.
When returned media is actually reviewed, use ai-film-production.md §7: preserve accepted assets,
fix one causal variable per attempt and check both sides of each affected cut. Prompt/checker PASS
does not certify generated-image/video quality; do not launch or budget retries from this skill.
